# LittleFS for LN882H

A LittleFS wrapper for the LN882H (LibreTiny) platform, ported from the [ESP8266 Arduino core](https://github.com/esp8266/Arduino).

## Upstream

- **LittleFS core:** <https://github.com/littlefs-project/littlefs> (v2.2.x)
- **ESP8266 wrapper reference:** <https://github.com/esp8266/Arduino/tree/master/libraries/LittleFS>
